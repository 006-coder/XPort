## 💡 Overview

**XPORT** is a client-side, **zero-PII storage synthetic data engine** designed to ingest raw datasets, profile schema structures, detect PII, synthesize privacy-safe datasets, and validate fidelity using **Train Synthetic, Test Real (TSTR) scoring**. 

The entire platform runs as a standalone, single-file Web Application (HTML5/JavaScript) with optional cloud extensions for Google Gemini AI generation and Supabase storage persistence.

---

## ✨ Key Features

*   **Multi-Format Ingestion:** Drag-and-drop or upload file formats including `.csv`, `.json`, `.txt`, `.md`, `.pdf`, `.docx`, and `.xlsx`.
*   **Automatic Schema Profiling:** Automatically detects column types *(numeric, categorical, datetime, text)*, calculates missing value ratios, and flags sensitive PII fields.
*   **Client-Side Text Parsing:** Extracts unstructured text from document formats (via `PDF.js`) and dynamically infers tabular structures.
*   **AI-Powered & Local Synthesis:**
    *   **Gemini AI Engine:** Utilizes Google's `gemini-3.5-flash-lite` model for context-aware synthetic data generation.
    *   **Fallback Engine:** Built-in statistical pseudo-random generation engine that operates entirely offline if no API key is provided.
*   **TSTR & Fidelity Metrics:** Evaluates utility and privacy via TSTR scoring, Wasserstein Distance, Jensen-Shannon Divergence, and Privacy Protection scores.
*   **Theme Customization:** Seamlessly toggle between three visual modes: **Solar Clay** *(Neumorphic Default)*, **Cyber**, and **Ash**.

## 🚀 Quick Start

### 1. Running the Application
Because XPORT is packaged into a single standalone HTML file, no build tools, compilers, or package managers (`npm`/`yarn`) are required.

1. Save the code into an `index.html` file.
2. Double-click `index.html` to open it directly in any modern web browser.

Alternatively, spin up a simple local server instantly using:
```bash
npx serve .
```

### 2. Configuration (Optional)
To unlock AI-assisted schema extraction, advanced synthetic generation, and database persistence, configure your API credentials inside the `<script>` section of your `index.html`:

```javascript
const XPORT_CONFIG = {
  GEMINI_API_KEY: 'YOUR_GEMINI_API_KEY',     // Get from https://aistudio.google.com/apikey
  SUPABASE_URL: 'YOUR_SUPABASE_PROJECT_URL', // Get from Supabase Settings > API
  SUPABASE_ANON_KEY: 'YOUR_SUPABASE_ANON_KEY'// Get from Supabase Settings > API
};
```
*Note: If `GEMINI_API_KEY` is left blank, XPORT safely defaults to its internal, deterministic local generation engine.*

create table public.xport_sessions (
  id bigint generated by default as identity primary key,
  source_file text,
  format text,
  row_count integer,
  seed integer,
  schema_columns jsonb,
  inferred_domain text,
  checkpoint_data jsonb,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null

-- 2. Create Generated Rows Table
create table public.xport_rows (
  id bigint generated by default as identity primary key,
  session_id bigint references public.xport_sessions(id) on delete cascade,
  row_index integer,
  row_data jsonb,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

## 🛡️ Security & Privacy Statement

*   **In-Session Processing:** Uploaded files are parsed and processed purely inside the client's web browser session. Raw datasets are never transmitted to or stored on external servers, except when invoking the Google Gemini API (if explicitly configured).
*   **PII Scrubbing:** Built-in pseudonymization automatically replaces sensitive personal identifiers (such as SSNs, names, phone numbers, and emails) with mock synthetic placeholders during the generation process.
